# MD测试用例转Excel

## 工作流程

### 1. 读取MD文件
- 读取用户指定的MD文件,如果没给路径则在"E:\项目"搜索用户给的关键字
- 解析Markdown表格，提取表头和数据行

### 2. 转换为Excel
- 调用 `scripts/md_to_excel.py` 将MD表格写入Excel
- 自动设置单元格格式

### 3. 保存文件
- 输出到MD文件同目录下，扩展名改为 `.xlsx`

## 脚本用法

```bash
python md_to_excel.py "<md文件路径>" "<输出xlsx路径>"
```

## Excel模板标准格式

| 列 | 字段 | 格式要求 |
|----|------|----------|
| A | testNo（序号） | 数字1,2,3...顺序递增，居中 |
| B | 测试内容 | 左对齐+垂直居中+换行 |
| C | 测试点 | 左对齐+垂直居中+换行 |
| D | 测试条件 | 左对齐+垂直居中+换行 |
| E | 测试步骤 | 左对齐+垂直居中+换行 |
| F | 测试结果 | 左对齐+垂直居中+换行 |
| G | 测试截图 | 左对齐+垂直居中+换行 |
| H | 测试截图2 | 左对齐+垂直居中+换行 |

### 单元格样式要求

- **所有有内容的单元格**：全框线（上下左右）
- **表头行**：也需要全框线
- **换行**：测试步骤等多行内容需自动换行
- **对齐**：表头居中，用例内容垂直居中+左对齐
- **字体**：微软雅黑，字号11

## 注意事项
- 检测到目标Excel文件被WPS/Excel打开时，先关闭再操作
- MD表格中的 `<br>` 标签在Excel中转换为换行符
