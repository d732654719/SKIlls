# 测试用例转说明书场景

## 触发条件

用户要求将测试用例文件转换为MD格式的说明书场景时使用。

常用触发词（不区分全角/半角）：
- 转场景 / md转场景 / md场景
- excel转场景 / 用例转说明书
- 转说明书场景 / 生成说明书场景
- md用例转说明书

## 工作流程

### 1. 读取文件

读取用户指定路径的文件，有时候用户会直接说文件名,输入的文件名有时候不完全等于实际的文件名,你要模糊匹配它,在"E:/项目"中去搜索到它,它是一个表格文件或者是md文件.表格文件使用 `openpyxl` 库解析。从testNo一行以下是测试用例,上面是一些其他说明,不管它.

关键列映射：
- 第1列（testNo）：用例编号
- 第2列（测试点）：场景名称，优先读此列
- 第3列（测试内容）：若测试点为空则读此列
- 第4列（测试条件）：条件
- 第5列（测试步骤）：步骤
- 第6列（预期结果）：结果

### 2. 转换为MD格式

输出格式：

```markdown
# 文件标题（从路径提取）

#### 场景N：场景名称

**条件：** 条件内容（精简合并）

**步骤：** 步骤内容（精简合并，用 → 连接）

**结果：** 预期结果
```

**注意：**
- 场景标题固定四个 `#` 即 `#### 场景`
- 场景之间不加 `---` 等分割线
- 内容要精简，条件和步骤不啰嗦
- 测试点为空时读测试内容列
- 有时候用户会指定输出那几个用例,比如输出用例1-4,用例8,那么输出的场景依然从1按顺序排列,而不是1,2,3,4,8

### 3. 保存文件

保存到测试用例同目录下，命名复制测试用例文件的名称+说明书场景）

## 执行示例

读取 `E:\项目\XX项目\XX-用例`，输出到 `E:\项目\XX项目\XX-用例说明书场景.md`
