## 常用触发词（不区分全角/半角）
- 复制模板 / 拷贝模板 / 新建项目模板
- copyfile / 拉模板 / 用模板
- 创建项目文件夹并用XX模板

## 工作流程

1. 和用户确认**项目文件夹名**和**模板名称关键词**
2. 调用 `scripts/copyfile.py` 执行复制、重命名并自动打开文件

## 脚本用法

```bash
python scripts/copyfile.py "<项目文件夹名>" "<模板名称关键词>"
```

## 模板关键词参考

| 关键词 | 匹配的模板文件 |
|--------|---------------|
| 充电 | -用例(充电模板).xlsx |
| 医院 | -用例(医院模板).xlsx |
| 常规 | -用例(常规模板).xlsx |
| 报表 | -用例(报表模板).xlsx |
| 空模板 | -用例(空模板).xlsx |
| 第三方 | -对接第三方支付测试用例模板.xlsx |
| 提前 | 提前缴费模板.xlsx |

## 注意事项
- 模板关键词支持模糊匹配，输入文件名中任意一段即可
- 匹配到多个文件时会全部复制
- 项目文件夹会创建在 `E:\项目` 目录下
- 复制重命名完成后会用系统默认程序自动打开文件
